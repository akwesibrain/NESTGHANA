# Location seed version 1

`locations-v1.sql` contains the initial region/town/area hierarchy. The named region examples (Adjei Kojo in Greater Accra, Tafo in Ashanti, and Akim Tafo in Eastern) are taken from the owner-provided security specification. The initial towns/areas are limited to names already present in the NestGH static site. This is a minimal bootstrap, not a complete authoritative Ghana gazetteer; verify it with the owner before production and expand only from an approved source.
